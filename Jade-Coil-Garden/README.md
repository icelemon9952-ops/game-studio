# Classic Snake: Jade Coil Garden

`Classic Snake: Jade Coil Garden` 是一个浏览器版贪吃蛇小游戏。它保留了经典贪吃蛇的核心玩法：控制蛇移动、吃掉食物、不断变长、尽量拿到更高分；同时加入了穿墙、尖刺、连击、Boost、每日挑战、成长等级和皮肤解锁等机制。

## 快速开始

直接用浏览器打开 `index.html` 即可开始游戏。

如果你把项目放在 GitHub Pages 或本地静态服务器中，也可以通过页面访问：

```text
Jade-Coil-Garden/index.html
```

项目不需要安装依赖，也不需要构建步骤。

## 游戏目标

你的目标是在 18 x 18 的棋盘上尽可能吃到更多食物、获得更高分，并避免撞到自己的身体或尖刺格。

蛇初始长度为 4。每吃到食物，蛇会变长、得分会增加，游戏节奏也会逐渐变快。若你填满整个棋盘、没有可生成食物的空格，会触发 `Perfect Run`。

## 操作指南

| 操作 | 键盘 | 触屏 / 鼠标 |
| --- | --- | --- |
| 开始游戏 | `Space` | 点击开始覆盖层 |
| 重新开始 | 游戏结束后按 `Space` | 点击结束覆盖层 |
| 向上移动 | `ArrowUp` 或 `W` | 上滑，或点击 `Up` |
| 向下移动 | `ArrowDown` 或 `S` | 下滑，或点击 `Down` |
| 向左移动 | `ArrowLeft` 或 `A` | 左滑，或点击 `Left` |
| 向右移动 | `ArrowRight` 或 `D` | 右滑，或点击 `Right` |
| 使用 Boost | `Shift` 或 `B` | 点击 `Boost` |
| 暂停 / 继续 | `P` | 点击 `Pause`，暂停时也可点击覆盖层继续 |
| 切换每日挑战 | `C` | 使用页面中的每日挑战状态面板查看进度 |

移动时不能直接反向掉头。例如蛇正在向右移动时，不能立刻输入向左。游戏最多会缓存 2 个转向输入，所以连续快速转弯时仍然比较跟手。

## 基础规则

- 墙壁会穿越：从棋盘一侧出去，会从另一侧回来。
- 撞到自己的身体会结束本局。
- 撞到已经成型的尖刺格会结束本局。
- Boost 期间可以短时间穿过自己的身体，但仍然会被尖刺击败。
- 游戏窗口失焦或页面被隐藏时，当前局会自动暂停。
- 棋盘没有空格可生成新食物时，会判定为完美通关。

## 食物规则

游戏中有两种食物：

| 食物 | 分数基础值 | 成长 | Boost 充能 | 说明 |
| --- | ---: | ---: | ---: | --- |
| 普通食物 | 12 | +1 | +1 | 最常见的食物，稳定成长和得分 |
| 琥珀奖励食物 | 28 | +2 | +2 | 分数更高、成长更多，约 18% 概率出现；每吃到 6 个食物后下一颗也会保底变成奖励食物 |

吃到食物后会立即刷新下一颗食物。如果棋盘没有空余位置，游戏会触发完美通关。

## 得分机制

每次吃到食物时，基础分会乘以当前连击倍率。连击倍率最高为 `x6`。

- 在连击时间窗口内连续吃食物，连击会提升。
- 超过当前模式的连击时间窗口后再吃食物，连击会回到 `x1`。
- Boost 生效时吃到食物，会额外增加一次分数倍率，但会重置 Lotus 连续计数。
- 食物靠近尖刺或尖刺预警格时会变成 `Bold Food`，吃掉它会获得额外勇气分。
- 不使用 Boost 的情况下连续完成 4 次快速拾取，会触发 `Lotus` 奖励分。

## 尖刺规则

随着吃到的食物数量增加，棋盘会出现尖刺预警格。预警格会在短时间后硬化为真正的尖刺格。

- 尖刺预警会尽量生成在离蛇头较远的空格。
- 普通模式下，预警约 0.95 秒后变成尖刺。
- 每日挑战中的 `Quick Thorns` 修改器会把预警时间缩短到约 0.72 秒。
- 尖刺格是绝对致命的，Boost 也无法抵消。

不同模式下，尖刺出现频率和最大数量不同。速度越快的模式，尖刺压力越高。

## Boost 机制

Boost 是一个短时间保命工具。

吃食物会为 Boost 充能。充能满后，按 `Shift` 或 `B` 可以触发 Boost。

Boost 生效时：

- 可以穿过自己的身体。
- 当前速度会进一步加快。
- Lotus 连续计数会被暂停 / 重置。
- 不能穿过尖刺格。

不同模式的 Boost 成本不同：Classic 需要 5 点充能，Standard 需要 6 点充能，Fast 需要 7 点充能。

## 游戏模式

| 模式 | 页面名称 | 特点 | Boost 成本 | 尖刺压力 |
| --- | --- | --- | ---: | --- |
| Classic | Classic | 起步较慢，连击窗口更宽，适合熟悉规则 | 5 | 较低 |
| Standard | Standard | 速度和尖刺节奏比较均衡 | 6 | 中等 |
| Fast | Fast | 速度更快，转向压力更高，尖刺出现更频繁 | 7 | 较高 |

选择模式后按 `Space` 开始。本局进行中不能随意切换模式。

## 每日挑战

按 `C` 可以进入或退出 `Daily Coil` 每日挑战。

每日挑战会根据当天日期生成固定种子，包含：

- 一个锁定的游戏模式。
- 一个挑战修改器。
- 两个当天目标。

挑战修改器包括：

| 修改器 | 效果 |
| --- | --- |
| Lean Reserve | Boost 需要额外 2 点充能 |
| Quick Thorns | 尖刺预警更快硬化 |
| Tight Rhythm | 连击窗口缩短 0.7 秒 |

每日目标可能要求你达到指定分数、长度、食物数量、Bold Food 次数、琥珀食物数量、Lotus 次数或最高连击。每日挑战记录会保存在当前设备的浏览器本地存储中。

## 成长与奖励

每局结束后，游戏会根据你的表现结算成长和奖励。

### Career XP

职业经验会根据分数、吃到的食物、琥珀食物、Bold Food、Lotus、最高连击和完美通关奖励计算。经验累计后会提升职业等级。

职业等级顺序：

1. Rookie
2. Street Crawler
3. Grid Captain
4. Spike Tactician
5. Coil Commander
6. Arcade Legend

### Petals

每局会获得 `Petals`，用于解锁皮肤。Petals 会根据分数、食物数量、长度、琥珀食物、完美通关和每日挑战奖励计算。

可解锁皮肤：

| 皮肤 | 花费 | 说明 |
| --- | ---: | --- |
| Garden Classic | 0 | 默认皮肤 |
| Amber Drift | 45 | 偏暖色、高对比的街机外观 |
| Moonlit Jade | 95 | 更冷静柔和的玉色外观 |
| Night Bloom | 160 | 更深色、更风格化的高级外观 |

## 页面设置

游戏包含一些会保存在当前设备上的设置：

- 声音开关。
- 减少视觉效果。
- 操作提示显示模式：完整、简洁、关闭。
- 已解锁皮肤和当前装备皮肤。
- 最佳分数、职业经验、每日挑战记录等进度。

这些数据保存在浏览器的 `localStorage` 中。清理浏览器站点数据会重置进度。

## 项目文件

```text
Jade-Coil-Garden/
├── index.html
├── jade-coil-garden.css
├── jade-coil-garden.js
├── jade-coil-garden-ui.css
└── jade-coil-garden-ui.js
```

`jade-coil-garden.js` 负责核心游戏逻辑，`jade-coil-garden-ui.js` 负责奖励、皮肤、每日挑战展示、设置和新手引导等产品层体验。

## 开发说明

- 这是一个纯前端项目，不依赖后端服务。
- 使用 HTML、CSS 和原生 JavaScript 编写。
- 游戏画面使用 `<canvas>` 绘制。
- 进度和设置使用浏览器本地存储保存。
- 修改代码后直接刷新浏览器即可看到效果。
